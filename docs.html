Architecture & Principles

Versaly APIs are designed around predictability, zero runtime bloat, and sub-10ms response times. All endpoints accept and return UTF-8 JSON payloads over HTTPS.

Our REST endpoints follow standard HTTP response code semantics: 200 OK for successful retrieval, 201 Created for resource creation, 400 Bad Request for malformed payloads, 401 Unauthorized for invalid authentication tokens, and 422 Unprocessable Entity for schema validation errors.

Authentication & Tokens

Public catalog and health endpoints require no credentials. Administrative endpoints, CRM updates, and internal ingestion pipelines require a Bearer token in the Authorization header: 

curl -X GET "https://versaly.example.com/api/admin/stats" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -H "Accept: application/json"

Submit Inquiries & Demo Requests

POST /api/submit

Receives structured prospective customer inquiries, demo requests, and custom development leads. Submissions are filtered through automated bot honeypots and time-to-submit verification. 

curl -X POST "https://versaly.example.com/api/submit" \
  -H "Content-Type: application/json" \
  -d '{
    "form_type": "demo_request",
    "name": "Alex Mercer",
    "email": "alex@apexlogistics.io",
    "company": "Apex Logistics",
    "product": "makersuite",
    "message": "Evaluating warehouse inventory telemetry.",
    "_ts": 1789345000000,
    "_hp_company": ""
  }'

Retrieve Products Catalogue

GET /api/products

Returns an array of published products, their industry classifications, current release status, feature highlights, and screenshot gallery metadata. 

curl -X GET "https://versaly.example.com/api/products" \
  -H "Accept: application/json"

Outbound Webhooks

When configured via WEBHOOK_URL in .env, Versaly forwards real-time lead submissions to your Slack channel, Zapier pipeline, or CRM endpoint in the following JSON schema:

JSON Payload Schema 
{
  "event": "lead_submitted",
  "ref_id": "versaly-2026-X8K9L2",
  "timestamp": "2026-09-14T04:30:00.000Z",
  "contact": {
    "name": "Sarah Connor",
    "email": "sarah@cyberdyne-health.com",
    "company": "Cyberdyne Health"
  },
  "details": {
    "product_name": "ClinicOS",
    "industry": "Healthcare & Clinical",
    "goal": "Replacing legacy EMR software"
  }
}
